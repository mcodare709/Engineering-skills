# Caveman

Use [caveman](https://github.com/mcodare709/Engineering-skills/tree/main/skills/caveman "caveman") as the canonical output-compression reference for `study-work`.

Default `study-work` output follows `caveman full`: terse technical prose, no filler, exact code/API/error/path/parameter preservation.

Use `lite` when full grammar improves readability. Use `ultra` only when compression does not remove technical meaning.

Temporarily drop compression for security warnings, destructive or irreversible actions, ambiguous ordered procedures, or clarification after the user reports confusion.
